# AC to DC Converter (Bridge Rectifier)

A simple AC to DC conversion circuit designed in **KiCad**, consisting of a full-bridge rectifier using 1N4007 diodes, filter capacitor, and an indicator LED. This circuit converts AC input to a DC output suitable for low-power applications.

---

## 🔧 Circuit Components
- 4 × 1N4007 Diodes (Full Bridge Rectifier)
- Electrolytic Capacitor (Filter)
- LED Indicator
- Current Limiting Resistor
- Screw Terminal Inputs/Outputs

---

## ⚙️ Working Principle

The AC input is fed into a **bridge rectifier**, which converts alternating current into pulsating DC.  
A filter capacitor smooths the pulsations, producing a more stable DC voltage.  
An LED indicator is included to show circuit output status.
